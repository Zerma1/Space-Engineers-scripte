# Space Engineers : scripts optimisés

Avant tout travail, lire `IA/Lisez-moi IA.md` : il indique quoi lire (conventions, suivi, jalons, conversations) et dans quel ordre.

Les rôles des agents sont décrits dans `agents/` : l'orchestrateur dans `agents/ORCHESTRATEUR.md`, toi dans le fichier qui porte ton rôle (`agents/git.md`, `agents/reviewer.md`…). Toute consigne à un autre modèle passe par `IA/Prompteur/relais.ps1`.

- Les scripts et leurs notes sont dans `Scripts/` ; les originaux dans `_old/` ne se modifient pas.
- Git (commits, branches, push, milestones, issues, PR) : voir `agents/git.md` et le §3 de `IA/Playbook IA.md` ; règles de code dans `Scripts/Conventions du projet.md`.
- Mettre à jour `IA/Suivi IA.md` à chaque étape terminée.
